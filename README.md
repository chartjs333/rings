# RINGS + Drosophila connectome

Экспериментальная модель **«один нейрон коннектома — один фазовый узел RINGS»**.
Направленные связи и их знаки загружаются из данных дрозофилы; внутри узла работают
фаза и затвор. Это новая вычислительная архитектура, а не подтверждённая
биофизическая эмуляция мозга или готовая виртуальная муха с телом.

## Возможности

- Разреженная сеть произвольного размера, матрица `W[post, pre]`, синхронное обновление.
- Возбуждающие и тормозные входы, неотрицательная безразмерная выходная активность.
- Стимуляция и отключение нейронов по точным строковым ID, включая ID больше `2^53`.
- Контроль фиксированного расписания затворов; четыре согласованных условия при отключении.
- Сводки затворов `p01/p10` без переходов между независимыми эпизодами.
- CSV-импорт, CSR-графы с контрольными суммами, загрузчик закреплённых данных FlyWire v783.
- Исходники из предоставленного архива: `original/rings_cifar10/`;
  контрольные суммы: `original/SOURCE_MANIFEST.json`.

## Быстрый запуск

Python 3.10 или новее, из корня репозитория:

```bash
python -m pip install -e .
python -m unittest discover -s tests -v
python -m rings_fly demo --out .runtime/toy_demo
```

`demo` использует **синтетическую четырёхузловую цепь** для проверки программы.
Она не выдаётся за данные дрозофилы. Выходной каталог должен быть новым или пустым.

## Реальные нейроны FlyWire

```bash
python -m pip install -e '.[flywire]'
python scripts/download_flywire.py --max-nodes 256
python scripts/run_flywire_smoke.py
```

Загрузчик получает около 104 МБ таблиц из закреплённого коммита
`philshiu/Drosophila_brain_model`, проверяет размер, Git blob SHA-1, SHA-256 и
соответствие ID/индексов, затем выделяет ограниченный подграф.

Он включает доступные в v783 сахарочувствительные нейроны из примера авторов,
MN9 и наиболее сильно связанные прямые мишени входных нейронов. Отсутствующие ID
и связи за границами подграфа явно записываются. **Это не полная цепь кормления.**

В выполненной проверке: **256 нейронов, 10 095 направленных связей, 20 входных
сахарочувствительных нейронов**. Выходы активируются, а отключение всех
стимулируемых входов обнуляет ответ. Это инженерная проверка загрузки и
распространения активности, не подтверждение поведения животного.

Результаты: `.runtime/flywire_smoke/summary.json` и компактные CSV выбранных
выходов. Полная пошаговая трасса мозга не сохраняется.
Подробности: [docs/VALIDATION.md](docs/VALIDATION.md).

## Свои таблицы

Заголовки `nodes.csv`: `neuron_id,sign`. Заголовки `connections.csv`:
`pre_id,post_id,syn_count`. ID читаются строками; веса одинаковых рёбер суммируются.

```bash
python -m rings_fly import-csv \
  --neurons nodes.csv --connections connections.csv \
  --source 'название, версия и URL данных' --out .runtime/my_graph

python -m rings_fly run \
  --connectome .runtime/my_graph \
  --stimulate INPUT_ID --readout OUTPUT_ID --silence INPUT_ID \
  --steps 400 --out .runtime/my_experiment
```

Замените `INPUT_ID`/`OUTPUT_ID` на ID из своих таблиц. При колонке `nt_type`
вместо `sign` нужна явная таблица предположений `--nt-signs signs.json`.
Неизвестные нейромедиаторы по умолчанию вызывают ошибку; политика
`--unknown-nt zero` выбирается явно и записывается в метаданные.

Нормировка `row_abs` делит строку на `max(1, sum(abs(row)))`. Она меняет
абсолютную силу входов. Для сырых весов есть `--normalization none`;
их устойчивость необходимо проверять отдельно.

## Отличия и границы

В исходном RINGS соседние пиксели входят через контрастный оператор. Здесь он
заменён взвешенной суммой по графу, выход дополнительно выпрямляется. RGB-вход,
CIFAR-readout и четыре повторения одного изображения не используются.
`carrier_hz=10` — демонстрационный параметр, а не измеренная частота нейронов.
Прежние 6 Гц ЭЭГ-эксперимента сюда автоматически не переносятся.

Тело NeuroMechFly, управление мышцами и пластичность ещё не подключены.
Сравнение с опубликованным LIF-симулятором и независимыми биологическими данными
остаётся следующим исследовательским этапом. Контроль `fixed_gate` сохраняет
выпрямление и потому тоже нелинеен.
