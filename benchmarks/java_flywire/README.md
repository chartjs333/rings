# Java и C++ на полной таблице FlyWire v783

Java успешно выполнила тот же расчёт RINGS. По медиане трёх запусков её
скорость составила 97,0% от C++ на одном потоке и 98,5% на четырёх.
В этом эксперименте перенос на Java почти не изменил производительность.

[Успешный запуск GitHub Actions](https://github.com/chartjs333/rings/actions/runs/46013033626) выполнен 27 ноября 2026 года.
Исходный код измерения: [`d6d0f38`](https://github.com/chartjs333/rings/commit/d6d0f38ed80bf82eeedf8f35b18224e2e4c2407c).
Локальная среда исполнителя была недоступна; все опубликованные здесь замеры
выполнены самостоятельно запущенным workflow на одном GitHub runner.

## Результаты

138 639 нейронов, 15 091 983 направленных связи; реальные данные v783,
точность float64/double, одна и та же топология, стимул и формулы RINGS.
Измеряется число шагов всей сети в секунду.

| Реализация | Рабочих потоков | Медиана, шагов/с | Диапазон трёх запусков | Скорость относительно C++ с тем же числом потоков |
|---|---:|---:|---:|---:|
| C++ | 1 | 53.19 | 52.80–54.10 | 100.00% |
| C++ | 4 | 151.01 | 150.99–151.44 | 100.00% |
| Java, обычные потоки | 1 | 51.59 | 51.45–52.53 | 96.99% |
| Java, обычные потоки | 4 | 148.71 | 145.04–148.88 | 98.47% |
| Java, виртуальные потоки | 4 | 140.85 | 139.87–145.25 | 93.27% |

На четырёх обычных потоках Java достигла 148,71 шага/с против 151,01 у C++:
скорость ниже на 1,53%. Java на четырёх потоках быстрее своей однопоточной
версии в 2,88 раза. Виртуальные потоки в этом запуске дали 140,85 шага/с,
то есть на 5,28% меньше обычных Java-потоков.

При шаге модели 1 мс нужно 1000 шагов/с для реального времени. Этой Java-версии
нужно ещё примерно 6,72-кратное ускорение. Расчёт 400 шагов соответствует
0,4 с модельного времени.

## Проверка правильности

- Отдельные нетаймированные запуски сравнили Java (обычные 1/4 и виртуальные
  4 потока) с C++ после каждого из 400 шагов: все активности, фазы и ворота
  каждого нейрона совпали побитово. Максимальные ошибки фаз и активности: 0.
- Все 15 файлов конечного состояния из измеряемых запусков имеют один SHA-256:
  `c0ff43c03b398bb38a1f75e099090363e7073d4b043f49befdcb2252040b0924`.
- После 400 шагов: 56 723 ненулевые активности; сумма активностей
  1.4130037880924333; сумма фаз 0.4477659423205264 во всех вариантах.
- Компиляция C++/Java, C++ graph test, 25 Python-тестов и Java self-test прошли.
  Java self-test проверяет знаковые связи, границы фаз/ворот, большие фазы,
  отключение нейронов, отбрасывание нечисловых состояний и режимы потоков.
- SHA-256 общего графа:
  `61203093733cffe0cde4fb60c5059fb2b76ddb1bb8576e574320ef765079ccb9`.

Совпадение установлено для этой траектории и дополнительных тестов; это не
доказательство побитового равенства для любых входов и параметров.

## Условия измерения

- CPU: Intel(R) Xeon(R) 6975P-C; доступны логические процессоры 0–3.
- Ubuntu 24.04 GitHub-hosted runner, Linux x86-64.
- Temurin JDK 21.0.13+9; g++ (Ubuntu 13.3.0-6ubuntu2~24.04.1) 13.3.0.
- C++: `-O3 -std=c++17 -fopenmp -ffp-contract=off -Wall -Wextra`.
- Java: `-Xms1g -Xmx1g -XX:-UseFMA`; число доступных JVM процессоров
  соответствует числу рабочих потоков; виртуальных carrier-потоков — четыре.
- 600 шагов прогрева в отдельной сети, затем сброс состояния и 400 измеряемых
  шагов. Три свежих процесса на конфигурацию, всего 15 измерений.
- Все варианты запускаются последовательно в перемешанном порядке с seed 783.
  CPU affinity одинакова для Java и C++ с тем же числом потоков.
- Время включает только цикл шагов. Загрузка, создание сети, прогрев,
  проверка, экспорт и итоговое суммирование исключены.
- Точность double, последовательный порядок сложения синаптических входов,
  параметры: dt=0.001, hz=10, gain=1, coupling=0.4, width=pi/2.
  Постоянный единичный вход: root ID 720575940624963786.

Во время измерений Java не было сборок мусора. Счётчик времени JIT-компиляции
вырос на 0–8 мс для одного обычного потока, 6–11 мс для четырёх обычных и
43–111 мс для четырёх виртуальных потоков. Это время компиляции может
перекрываться с вычислениями; его нельзя просто вычитать из времени замера.
600 шагов прогрева не означают полного прекращения JIT.

## Границы вывода и воспроизведение

Это сравнение данных реализаций на одном сервере, а не универсальный рейтинг
языков. Небольшие различия могут зависеть от среды и прогрева. Сравнение
использует C++ из этого же запуска, а не прежние результаты на другом CPU.
Java использует постоянных работников и координирующий поток; OpenMP
организует работу иначе. Виртуальный вариант создаёт четыре рабочих потока,
а не отдельный поток для каждого нейрона.

Обработана вся закреплённая исходная таблица FlyWire v783. Модель динамики —
RINGS; измерение скорости не подтверждает биологическую точность модели.
Java-загрузчик ограничен файлами меньше 2 GiB; текущий граф занимает
183 322 052 байта и укладывается в ограничение.
