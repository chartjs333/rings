# Чакона Баха на сети RINGS

Рендерер превращает партитуру для скрипки соло из Партиты № 2 ре минор, BWV 1004, в звуковой отклик модели FlyWire. В [комплектном MIDI](../music/bach-chaconne-bwv1004.mid) 3 085 нот, диапазон G3–G6, размер 3/4, длительность 12:50. [Источник MIDI и лицензия](../music/README.md).

## Запуск в Windows

Команды выполняются в PowerShell из каталога проекта. Для уже запущенного бенчмарка используются те же JDK 21+, Python и граф в `.runtime/java_graph/graph.bin`. На новом компьютере сначала [подготовьте граф](JAVA_WINDOWS.md). В Linux и macOS синтаксис такой же, только вместо `.\.venv\Scripts\python.exe` укажите `python3` из вашей среды.

1. Обновите ветку проекта.

   ```powershell
   git switch codex/java-flywire-benchmark
   git pull --ff-only
   ```

2. Для пробы запишите первые четыре секунды.

   ```powershell
   .\.venv\Scripts\python.exe scripts/render_chaconne.py --duration-ms 4000 --output .runtime/chaconne-preview.wav
   ```

   При первом запуске программа загрузит анатомические координаты, проверит контрольные суммы и сохранит подготовленный CSV. Граф загружается с диска. Последующие запуски используют тот же CSV. Для ранее подготовленных данных в другом каталоге укажите `--graph` и `--coords`.

3. Прослушайте фрагмент.

   ```powershell
   Start-Process .runtime/chaconne-preview.wav
   ```

4. Для полной партитуры запустите без ограничения длительности.

   ```powershell
   .\.venv\Scripts\python.exe scripts/render_chaconne.py --output .runtime/chaconne-full.wav
   ```

Это офлайн-расчёт на CPU. Он выполняет несколько независимых симуляций за каждую секунду партитуры и может занять много часов. В терминале отображается обрабатываемая MIDI-высота. Временные дорожки сохраняются рядом с выходным WAV, поэтому при полном запуске предусмотрите несколько гигабайт свободного места. Итоговый файл записывается после расчёта общей шкалы расстояний.

## Как устроен звук

**Вход.** Каждый полутон имеет собственное состояние сети. Пока соответствующая клавиша нажата, нейрон `720575940624963786` получает постоянный вход 1, после отпускания — 0. Остальные нейроны получают сигнал по синаптическим связям. Граф, шаг 1 мс и исходная динамика RINGS у всех голосов одинаковы. Состояние сохраняется между нотами одной высоты. При наложении нот одной высоты вход остаётся включённым до отпускания последней. Громкость нажатия для этого эксперимента фиксирована (в комплектном MIDI для всех нот velocity 90).

**Аккорды и время.** Начала и окончания нот рассчитываются из MIDI с учётом темпа и округляются до ближайшей миллисекунды. Каждая высота обрабатывается в своём проходе по одному музыкальному времени. Так один граф помещается в память, а в WAV все голоса аккорда звучат одновременно. Из 37 полутонов диапазона 36 встречаются в этой редакции.

**Расстояние и громкость.** Для каждого нейрона вычисляется евклидово расстояние между его анатомической опорной точкой и опорной точкой входного нейрона. Общий максимум расстояния берётся среди нейронов с выходной активностью строго выше порога во всех голосах и на всех шагах выбранного отрезка. Рендер фрагмента использует собственный максимум, поэтому его модуляция и общая громкость могут отличаться от той же части полного рендера.

**Синтез.** Высоте MIDI соответствует базовая частота при A4 = 440 Гц. Для относительной дистанции `r = расстояние / максимум` и заданного разброса `s` в центах звучат частоты `f × 2^(+s×r/1200)` и `f × 2^(-s×r/1200)`. Каждой выделяется половина амплитуды отклика. При нулевом расстоянии звучит базовая частота. Звуки всех активных нейронов и всех голосов складываются. Пространственное расстояние управляет высотой, а время возникновения отклика задаёт сама сеть. Порог действует на озвучивание, динамика модели сохраняет малые активности.

Выход — моно WAV PCM16, 44,1 кГц. Огибающие меняются плавно между отсчётами модели; фазы звуковых генераторов непрерывны. Пиковая громкость нормируется один раз для всего файла. После конца партитуры по умолчанию отводится 250 мс на отклик сети; WAV завершается плавным переходом к тишине длительностью 1 мс. Полный WAV при настройках по умолчанию длится 770,251 с.

| Параметр | По умолчанию | Назначение |
|---|---:|---|
| `--duration-ms` | вся пьеса | Верхняя граница длительности симуляции от начала MIDI |
| `--tail-ms` | 250 | Продолжение расчёта сети после конца MIDI |
| `--spread-cents` | 50 | Максимальное отклонение вверх и вниз, от 0 до 50 центов |
| `--threshold` | 0.001 | Минимальная выходная активность для озвучивания; сравнение строгое |
| `--threads` | 4 | Рабочие потоки расчёта одной копии сети |
| `--stimulus` | 720575940624963786 | Входной нейрон, один и тот же во всех копиях |
| `--midi` | MIDI из каталога music | Другой файл MIDI формата 0/1 с временной шкалой PPQ |

## Геометрия FlyWire v783

Для 138 625 клеток взята опорная точка `pos_x/y/z` из [аннотаций FlyWire](https://github.com/flyconnectome/flywire_annotations/tree/a83b2776d60d5764cef36b927f5f9679c16c47a2/supplemental_files). Для остальных 14 использована существующая отметка проверяющего из таблицы координат FlyWire Codex v783. Все расстояния вычисляются в микрометрах. Входная точка — (469,732; 379,276; 117,520) мкм. Идентификаторы, источники, преобразования единиц и выбор 14 отметок можно проверить в `.runtime/chaconne-coordinates.json`.
