# Модель и интерпретация

## Динамика

CSR-матрица хранит веса как `W[post, pre]`: строка — получатель, столбец —
отправитель. Каждый узел хранит фазу `phi` и безразмерную неотрицательную активность `a`.

```text
drive(t) = external(t) + coupling * W @ a(t-1)
phi(t)   = wrap(phi(t-1) + 2*pi*carrier_hz*dt + sensitivity*drive(t)*dt)
gate(t)  = abs(phi(t)) <= half_width
a(t)     = gate(t) * max(0, drive(t))
```

Все узлы читают старое состояние; `wrap` возвращает фазу в `[-pi, pi)`.
Частота, чувствительность и полуширина могут быть скалярами или массивами по узлам.
Выход не калиброван в импульсах/секунду. Торможение задаётся знаком связи;
отрицательный вход не становится отрицательными импульсами.

## Связь с исходником

Из `original/rings_cifar10/rings.hpp` взяты идея входозависимой фазы и затвор.
Изменены оператор связности и выходная активность. Исходное выражение
`state - mean4(neighbors)` усиливает контраст, а не передаёт положительный
синаптический сигнал. Новая версия не ограничена 768 узлами или 16-битными
индексами, не использует RGB и не применяет веса CIFAR-readout как синапсы.

## Время и масштабирование

`dt_s` — секунды, `carrier_hz` — частота несущей узла,
`phase_sensitivity` — радианы в секунду на единицу безразмерного входа.
Рёбра имеют неявную задержку в один шаг. Изменение `dt_s` меняет и задержку
распространения: масштабирование фазовых параметров не гарантирует эквивалентность.

При `sum(abs(W[i,:])) <= 1`, ограниченном входе и `0 <= coupling < 1` действует
оценка `max(a(t)) <= max(abs(external(t))) + coupling * max(a(t-1))`.
Это вычислительная оценка, не физиологическая калибровка. Сырые веса требуют
отдельного контроля устойчивости. Настройки 10 Гц, coupling=0.4 и начальная
фаза 0 не подбирались по результатам реального подграфа.

## Отключение и контроль

`set_silenced` сразу обнуляет текущую активность и зажимает последующие выходы.
Фаза может продолжать изменяться: открытый затвор не равнозначен ненулевому сигналу.

При заданном отключении сравниваются четыре условия с одинаковыми графом,
стимулами и начальной фазой: RINGS; RINGS с отключением; `fixed_gate`;
`fixed_gate` с тем же отключением. `fixed_gate` означает sensitivity=0,
но сохраняет выпрямление, поэтому не является линейной моделью или LIF-бенчмарком.

## Сводки затворов

`p01=n01/(n00+n01)`, `p10=n10/(n10+n11)` вычисляются по явным состояниям затворов.
При нулевом знаменателе возвращаются NaN и флаг недоступности; JSON содержит
`null` и `valid=false`. `GateSummary.end_episode()` исключает переход между
эпизодами, сохраняя накопленные счётчики. Эти величины не доказывают марковость
биологической нейросети и могут отражать встроенную несущую фазового узла.

## Что устанавливает проверка

Прогон на реальном графе подтверждает загрузку и выполнение вычислений. Для
биологического вывода нужны заранее заданные реакции на стимулы и вмешательства,
независимые измерения, учёт отсечённых связей и сравнение с исходной нейронной
моделью. При дальнейшем подключении тела моторный интерфейс должен оставаться
одинаковым в сравниваемых вариантах.
