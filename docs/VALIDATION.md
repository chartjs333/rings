## Проверочный прогон

Команда: `PYTHONPATH=src python scripts/run_flywire_smoke.py` после загрузки данных.
400 шагов по 1 мс, воздействие на все 20 входов на шагах `[40, 320)`, амплитуда 1.
Нормировка входящих весов `row_abs`, coupling=0.4, carrier=10 Гц,
phase_sensitivity=1, half_width=pi/2, начальная фаза 0.

Первый выход выбирается до симуляции как наиболее сильная непосредственная
мишень входных клеток; второй — ID MN9 из примера источника.

| Условие | Средняя активность выбранной мишени | Средняя активность MN9 |
|---|---:|---:|
| RINGS | 0.08243375363 | 0.00050293331 |
| RINGS, все стимулируемые входы отключены | 0 | 0 |
| Fixed gate | 0.08231429685 | 0.00049547729 |
| Fixed gate, те же входы отключены | 0 | 0 |

Активность безразмерная. Это проверка работоспособности загрузки, распространения
сигналов и отключения, **не количественное воспроизведение физиологического ответа**.
Обнуление выхода при удалении всех источников сигнала ожидаемо и не является
новым биологическим предсказанием.

Для обоих выходов и всех четырёх условий p01=0.02 и p10≈0.02010050251.
Следовательно, эти переходные сводки в данном опыте **не различили условия**,
хотя амплитуды различались. Преимущество RINGS над контрольной моделью этим
прогоном не установлено; настройки после просмотра результата не подбирались.
