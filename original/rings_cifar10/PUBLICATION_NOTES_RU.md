## 1. Introduction

Поставить задачу компактного извлечения признаков на CPU без обратного распространения ошибки через клеточное ядро. Не утверждать, что все MLP/CNN требуют GPU или миллионы параметров. Обсудить клеточные сети, резервуарные вычисления, осцилляторные модели и random features после отдельного обзора первичной литературы; новизна пока не проверена.

Вклад: зависимые от изображения жесткие фазовые затворы, локальная пространственная связь, фиксированное ядро с обучаемым Ridge-readout, воспроизводимая системная реализация и сравнение с линейным контролем и MLP, включая отрицательные результаты.

## 2. Математическая модель

Пусть p_i — среднее RGB в блоке 2×2, деленное на 255; i=(r,c,k), сетка 16×16×3. Средняя яркость b_(r,c)=(p_R+p_G+p_B)/3. Нормализованный вход x_i=(p_i−μ_i)/σ_i и цветовое отклонение q_i=(p_i−b_(r,c))/σ_i. μ и σ оцениваются только по обучающей выборке.

Для четырех пространственных соседей того же канала с отражением на границах:

```
u_i(t) = x_i + λ_edge [s_i(t−1) − mean4(s_neighbors(t−1))] + λ_color q_i
θ_i(t) = wrap(θ_i(t−1) + ω + γ u_i(t))
s_i(t) = 1{|θ_i(t)| ≤ h} u_i(t)
```

Здесь λ_edge=0,4, λ_color=0,25, ω=π/2, γ=0,25, h=π/2. Полная угловая ширина окна — π, то есть 180°; h — полуширина 90°. wrap возвращает угол в [−π,π). Четыре шага синхронны: все соседи читаются из предыдущего состояния. Начальное состояние нулевое, начальные фазы фиксированы. Для независимой классификации каждого изображения состояние сбрасывается. Потоковый режим поддерживается, но его точность здесь не исследована.

Признаки F=concat((s(1)+s(2))/2, (s(3)+s(4))/2), размер 1536. Это сжатие временной последовательности с потерей информации о различиях внутри каждой пары, а не «сохранение всей динамики без потерь».

Оценки десяти классов z_k=w_k·F+b_k, ответ argmax_k z_k. Обучаются 15 370 параметров readout. Кольца не обучают базовые фазы между кадрами: входозависимая динамика не равнозначна локальному обучению. Ridge обучается обычной линейной алгеброй вне C++-ядра. Заявление «без backprop через кольца» корректно; «вся система без матриц» — нет.

## 3. Инженерная реализация

Описать прямую адресацию, двойной буфер синхронных состояний, floor-based wrap с резервной веткой для больших конечных аргументов, побитовое обнуление через memcpy/uint64_t и step<false> без упаковки активных индексов.

Различать разреженность значений и пропуск вычислений. Branchless-режим обходит все узлы, даже когда выходы нулевые. Без дизассемблирования конкретной сборки нельзя обещать отсутствие ветвлений на любом компиляторе. Ускорение всей версии не доказывает отдельный вклад каждой оптимизации без соответствующей абляции.

Задержка бинарной модели не переносится на 10-классовый readout: новый readout выполняет десять скалярных произведений. Измерены 44,72 мкс на одиночном кадре и 50,09 мкс/кадр в пакете. Для MLP — 49,14 и 35,41 мкс. Указать различие C++ float64 и NumPy/BLAS float32, число потоков, scope таймера, прогрев, распределение задержек и окружение. На микроконтроллерах эксперимент не проводился.

## 4. Эксперименты

### Бинарная задача: исторический результат и устойчивость

Одиночный прежний тест: фазовый фильтр 65,55%, MLP 64,05%, старый гибрид 63,60%. Эти значения не следует делать единственным доказательством превосходства.

Повторная 10-fold CV × 5 seeds по всем 12 000 cat/dog: фазовый 63,5283%, MLP 63,7683%; разность −0,24 п.п. Скорректированный тест Nadeau–Bengio: p≈0,716; 95% интервал разности [−1,556; +1,076] п.п. Превосходство не подтверждено. Это исследовательская оценка после разработки на тех же данных, а не полностью независимый финальный тест.

### Полный CIFAR-10

Привести таблицу из README с тремя моделями: 41,10% / 43,63% / 51,96%. Внутренний выбор настроек 40 000/10 000, финальное обучение 50 000, официальный тест 10 000. Сообщить факт предыдущего использования cat/dog части теста.

Фазовая модуляция: +2,53 п.п. против линейного контроля, точный МакНемар p=4,91e-9. Против MLP: −8,33 п.п., p=1,72e-57 в пользу MLP. Поправка Холма для двух сравнений не меняет вывод. ### Абляция

Приложенный график показывает прежний бинарный validation sweep gain={0,0,05,0,1,0,25,0,5,1} и alpha={10,100,1000,10000}. Значение 0,25 — лучший проверенный кандидат при alpha=1000 на одном разделении, не доказанный точный или универсальный оптимум. На полном CIFAR-10 оно зафиксировано, новая сетка gain не запускалась.

Ранее readout_bins=4 дал 64,45% на бинарном тесте против 65,55% для bins=2. Этот отрицательный результат уместно включить. Размер окна в текущем дополнении фиксирован; абляция ширины окна еще не проведена.

## 5. Conclusion

Подтверждена полезность фазовой нелинейности относительно линейного контроля при одинаковом размере обучаемого readout. В этой конфигурации MLP точнее на полном CIFAR-10 и быстрее в пакетном режиме. Более компактный readout и малая абсолютная задержка оправдывают дальнейшее исследование, но не вывод о замене глубоких сетей или пригодности для любого микроконтроллера.
